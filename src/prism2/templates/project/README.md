# PRISM2 model repository

Plain files that produce one life cycle inventory:

| File | What |
|---|---|
| `prism.yaml` | manifest: process type, data origin, model and gate settings, excluded runs |
| `scope.yaml` | the scope card: goal, functional unit, boundary, intended use, target tier |
| `feedstocks.yaml` | feedstock grades and the operating point |
| `data/runs.csv` | runs: one row per run, columns are the process type's field keys |
| `signoffs.yaml` | reviewer sign-offs |
| `decisions/` | decision records |
| `build/` | generated by `prism build`; never edit |

```bash
prism validate
prism design          # run sheet if you have no data yet
prism build
prism status
prism export xycle
```
