# Black mass leach (worked example)

A PRISM2 model repository. **The data is synthetic** (invented by `scripts/generate_samples.py`), so
every result is a demonstration. Two runs carry deliberate errors so the checks have something to find.

```bash
prism validate      # file:line findings
prism build --demo  # fit, certify, inventory, method note -> build/
prism export xycle --demo
```
